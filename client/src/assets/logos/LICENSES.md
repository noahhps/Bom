# Service logos

Bundled so the MCP gallery shows real marks without fetching anything: Bom is
often run offline, over a tailnet, and the project serves no assets from a
CDN. `lib/serviceLogos.js` maps service names to these files.

| Files | Source | Licence |
|---|---|---|
| atlassian, github, google-calendar, jira, linear, notion, sentry, stripe, supabase, vercel | [Simple Icons](https://simpleicons.org) 16.35.0 | CC0 1.0 |
| exa, figma, firecrawl, google, huggingface | [Lobe Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.98.0, `-color` variants) | MIT |
| playwright | [Devicon](https://devicon.dev) 2.17.0 (`playwright-original`) | MIT |

The marks themselves are trademarks of their owners, used here only to
identify the service each preset connects to.
